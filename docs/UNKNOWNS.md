|---|---|---|---|---|
| U-1 | P-1 | Native gateway USD capability | RESEARCHED | Reference project's September measurements describe costLimit policies newer than July Learn docs. Do not assume absence from Learn means unsupported. See ADR-0002. |
| U-2 | P-1 | Identity and asset-scoped native permissions | RESEARCHED | Portal Sept 24 changelog adds native Entra and alias-scoped RBAC, superseding July Learn. | U-3 | P-2 | Exact provider invoice cost | ASSUMED | Configured worst-case context and cache/output price ceilings bound list-price token spend only. Incorrect ceilings invalidate the bound; retain holds for missing/over-ceiling usage, reject server-side billed tools. Not an invoice reconciliation system. |
| U-4 | P-3 | Entra group changes without scheduled projection | RESEARCHED | Read transitive group memberships from Microsoft Graph at request time. Optional bounded TTL introduces documented revocation delay. Graph failure denies new requests. https://learn.microsoft.com/graph/api/directoryobject-getmemberobjects |
| U-5 | P-4 | Native model route activation in FDPO | RESEARCHED | Actual Entra and temporary-key native requests returned 200 after using AnthropicMessages and a callable alias; native quota subsequently returned 403. Direct Foundry remains explicit, never a silent fallback. |
| U-6 | P-4 | Free model usage / gateway pricing | RESEARCHED | Preview gateway pricing is not a promise of free model inference. Related resources and models can be billed. https://learn.microsoft.com/azure/api-management/ai-gateway-overview |
| U-7 | P-5 | 50k population versus concurrent capacity | ASSUMED | Validate population cardinality locally; publish actual throughput and concurrency. Managed DB / Graph / model quotas remain release constraints, not solved by counting users. |
| U-8 | P-3 | CLI versus Desktop enforceability | ASSUMED | Separate allowed Entra application IDs bind policy to token client identity, not executable. Public-client tokens are bearer credentials; do not promise binary attestation. |
| U-9 | P-6 | Intermittent Ubuntu PostgreSQL CI termination | RESOLVED | Recurred on Linux: pool end bookkeeping could finish before socket disconnect, racing fixture shutdown. Deterministic regression failed before client-end tracking and passes after it. Fix 4434a65 passed both platforms in CI run 38790507795; continue recurrence monitoring. |
| U-10 | P-6 | Live directory credential selection | RESOLVED | Recurrence showed Graph 404 and an ambient server credential from the wrong tenant. Explicit subscription-selected CLI credentials and bootstrap/probe bearer authentication returned Graph 200 and restored full live flow at 19:27 UTC. The earlier generic 503 is not retrospectively proven to have the same cause. Preserve failures and continue monitoring. |
| U-11 | P-7 | Native `counterKey []` pooling | RESOLVED | Live: after identity A exhausted a `counterKey []` limit, identity B was denied on its first call while its identity counter was far below its cap. One shared counter per policy instance (per alias). |
| U-12 | P-7 | Non-user (app/managed identity) tokens on native | RESOLVED | Live: user-assigned managed identity tokens for `https://azure-api.net/aigateway` returned 200 with alias-scope RBAC. App registrations untested (directory quota). |
| U-13 | P-7 | Claude Code `apiKeyHelper` against native | RESOLVED | Installed Claude Code 2.1.272 succeeded directly. The profile must pin `model` and `availableModels`, or user-level `enforceAvailableModels` silently selects another model. |
| U-14 | P-7 | Gateway-scope policy location | RESOLVED | `workspaces/default` PATCH `{properties:{policies}}` with `scope: workspace` capped calls to aliases live; removal restored them. |
| U-15 | P-7 | RBAC propagation / group principals | RESOLVED (negative) | Direct User/ServicePrincipal assignment: access in about 3 s, revoked about 64 s after deletion. Entra group assignment at alias scope (2026-10-19): a user who joined the group was still denied after 90 min; managed identities were denied for about 40 min (about 24 h documented MI cache). The gateway token has no groups claim, and ARM effective permissions omitted the group grant. The installer warns on Group principals; use User principals or governed mode. |
